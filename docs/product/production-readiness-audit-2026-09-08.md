## Notes

- This scan is a fresh pass, independent of `known-gaps.md` (which is fully closed — all 8 items resolved 2026-09-06 through 2026-09-08). No overlap between the two lists.
- Findings #4/#15/#16/#30 each surfaced independently from 2+ agents auditing different domains — cross-corroboration, not the same finding double-counted; kept as separate rows since each agent's own angle/evidence differs, but noted as such.
- Overall verdict from the scan: architecture is sound (hexagonal boundaries hold, admin authz is tight, CEL sandbox has no escape, TLS/secrets-rotation wiring is correct). Problems cluster in 3 places: pre-auth resource exhaustion (webhook body, metrics cardinality, rate-limiter-before-auth), features that silently no-op when an env var is unset (empty webhook secret), and things that look done but aren't wired to the real thing (composite indexes, purge sweeper, agent's field-path guard, listener reconnect). None require a redesign — most fixes are single-function.
